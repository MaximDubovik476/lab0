1.Git-это распределённая система контроля версий.
 Git решает несколько ключевых задач, которые возникают при работе с изменяющимися файлами (кодом, документацией, дизайном и т.д.).
2.Централизованные системы контроля версий:
  В таких системах единственный сервер хранит каноническую историю проекта. Разработчики получают рабочую копию с локального компьютера, вносят изменения и фиксируют их обратно на центральный сервер. 
  Распределённые системы контроля версий:
  Здесь каждый разработчик имеет полную локальную копию всего репозитория, включая всю историю изменений. Это позволяет работать в автономном режиме, а синхронизировать изменения с другими участниками — по мере готовности.
3.Репозиторий в Git — это хранилище, где содержатся все файлы вашего проекта и вся история их изменений.
