git clone- создаёт локальную копию удалённого репозитория по указанному URL. Часто используется для начала работы над чужим проектом. 
git status- показывает текущее состояние репозитория: какие файлы изменены, но не добавлены в индекс, какие ожидают коммита, есть ли неотслеживаемые файлы.
git add- добавляет изменения из рабочего каталога в индекс
git commit- эта команда фиксирует изменения в локальном репозитории.
git push- эта команда отправляет локальные коммиты в удалённый репозиторий, делая изменения доступными для других участников команды. 
git init- инициализирует новый Git-репозиторий в текущей папке.
git log- выводит историю коммитов в хронологическом порядке (от новых к старым).
git branch- создаёт новую ветку с указанным именем.
git checkout- переключает вас на указанную ветку и загружает её состояние в рабочий каталог.
git merge- объединяет указанную ветку с текущей.
